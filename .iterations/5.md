# Iteration 5 — Coherent UI redesign

Completely redesign Visor using the owner's shared UI preferences: neutral surfaces,
restrained accent colors, consistent typography, compact readable content, useful
alignment, predictable navigation, preserved context, and clear touch interactions.

## Scope and acceptance

- Give home, search, library, song details, playlist editing, playback, lyrics,
  filters, and selection dialogs a consistent responsive design.
- Use desktop side navigation and mobile bottom navigation. Make home an overview
  and search a focused catalogue view using one shared search state.
- Preserve search/filter/layout/selection state and playlist drafts across navigation;
  restore catalogue scroll after returning from a song detail.
- Preserve song metadata, manual and dynamic playlists, ordered editing, playback,
  queue controls, chord diagrams, and all existing data/API behavior.
- Use Swedish UI copy, semantic controls, visible focus, readable contrast, and
  minimum 44px interactive targets. Respect reduced motion and safe areas.
- Verify rendered desktop and mobile views and core interactions using isolated
  development data. Report synthetic verification separately from real-device work.
- Run the normal configured checks, backup, deployment, commit, and push workflow.
  Do not restore or replace production data.
